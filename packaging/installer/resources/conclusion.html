Installed

SourceGlo Pro is ready to use.

Finding it in your DAW

  • Most hosts pick up a new plug-in on their next launch. If SourceGlo Pro does not appear, run your DAW's plug-in rescan.
  • Logic Pro validates new Audio Units on launch; allow it to finish before opening a project.

Where to start

Drop it on a kick, 808 or vocal, pick the source type in the left panel and hit ANALYZE. The score ring, diagnostics and rescue list show the interface in action — in this preview build they run on demonstration data while the analysis engine is completed.

This is a test build for evaluation, not for release to customers.
