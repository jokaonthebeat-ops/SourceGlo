# Responsive Rules

The SourceGlo Pro interface is a fixed-aspect professional plugin layout. It is not a reflowing website.

1. Keep the design aspect ratio at 1491:1055.
2. Scale all X/Y coordinates, control sizes, radii, fonts, strokes, and icon sizes by one uniform factor.
3. Center the design when the host gives an area with a different aspect ratio.
4. Do not collapse the Source panel, Diagnostics panel, Rescue panel, or Macro bank.
5. Recommended scale presets: 70%, 80%, 90%, 100%, 110%, 125%, 150%.
6. Recommended minimum: 1044 × 739. Below that, preserve layout and let the host window enforce the minimum rather than rearranging controls.
7. Cache rescaled raster assets per discrete UI scale to prevent repeated resizing during paint.
