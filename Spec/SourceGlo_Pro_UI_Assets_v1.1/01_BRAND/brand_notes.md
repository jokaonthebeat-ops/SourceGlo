# SourceGlo Pro Premium Brand Notes

- The approved identity is the supplied premium metallic logo with the circular source-intelligence emblem.
- `sourceglo_pro_premium_logo_header_320x42.png` is the exact 1× asset for the plugin header.
- Use the 2× or 4× header asset at higher UI scales; do not upscale the 1× file.
- Use the trimmed 1024w/2048w files for product pages, installers, splash screens, boxes, thumbnails, and advertising.
- Use the 256/512/1024 premium mark for plugin icons, loading screens, bypass indicators, and compact branding.
- Keep the logo horizontal and left-aligned in the header at x=19, y=16, w=320, h=42 on the 1491×1055 base canvas.
- Do not redraw the lettering, substitute fonts, flatten it onto a plaque, recolor it, or use any earlier SourceGlo logo.
- The former simple SVG/PNG logo and former circular mark were intentionally removed from this package.
- These premium logo assets are raster PNG files with transparency; no replacement vector file is included.
