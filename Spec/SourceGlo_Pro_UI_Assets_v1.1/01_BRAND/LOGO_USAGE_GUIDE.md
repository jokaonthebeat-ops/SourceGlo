# SourceGlo Pro Premium Logo Usage Guide

## Plugin header

Use `sourceglo_pro_premium_logo_header_320x42.png` at the base UI size. Draw it at exactly `{19, 16, 320, 42}`. For 2× and 4× rendering, load the corresponding native-size asset rather than stretching the 1× image.

## Marketing and installer artwork

Use `sourceglo_pro_premium_logo_2048w.png` whenever the artwork has enough resolution. Use the 1024w file for web layouts where the larger file is unnecessary.

## Icon / emblem

Use the premium mark files for square icon placements. Preserve the full transparent padding and do not crop into the outer gold/cyan arcs.

## Prohibited

- Do not use any previous SourceGlo logo.
- Do not recreate the wordmark with a font.
- Do not add a black rectangle or extra badge behind it.
- Do not stretch the full marketing lockup into the compact header area; use the dedicated header asset.
- Do not separate or recolor the silver, gold, and cyan elements.
